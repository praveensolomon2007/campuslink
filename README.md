# CampusLink

> **Where Opportunities Meet People**

CampusLink is an AI-powered campus opportunity and participation platform designed to help students discover opportunities, understand requirements, find suitable teammates, and participate.

## Core Problem

Campus opportunities are often distributed across fragmented channels such as WhatsApp groups, posters, social media, department announcements, and separate registration forms.

Students may discover opportunities but still struggle to:

* understand requirements
* determine eligibility
* find the right teammates
* form teams
* get answers to questions
* participate effectively

Organizers also face challenges in distributing opportunities, answering repetitive questions, forming teams, and understanding participation.

## MVP

The CampusLink MVP focuses on one core journey:

**Discover → Understand → Connect → Participate**

### Student

1. View opportunities
2. Filter opportunities
3. Open an opportunity
4. Ask questions using AI
5. View available teams
6. Receive an AI-assisted team match
7. Request to join a team

### Organizer

1. Create an opportunity
2. Provide event information
3. Define eligibility and team requirements
4. Publish the opportunity

## Technology

* Frontend: React + Vite + JavaScript
* Backend: Python + FastAPI
* Database: PostgreSQL
* AI: LLM-based services
* Version Control: Git + GitHub

## Project Goal

Build a stable working proof of concept that demonstrates how CampusLink can connect students, opportunities, and teams through structured data and AI-assisted functionality.
